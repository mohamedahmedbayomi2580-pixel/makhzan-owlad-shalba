# مخزن أولاد شلبه — بناء APK عبر GitHub Actions

هذا المشروع يحتوي على ملف HTML الأصلي وإعدادات Capacitor وملف workflow لبناء APK على GitHub Actions؛ لا يحتاج إلى تثبيت Android Studio على الكمبيوتر المحلي.

## طريقة الاستخدام

1. فك ضغط هذا الملف.
2. سجّل الدخول إلى GitHub وأنشئ مستودعًا جديدًا (Repository)، مثل `makhzan-owlad-shalba`.
3. ارفع **كل محتويات المجلد** إلى المستودع، مع الحفاظ على مجلد `.github/workflows`.
   - تأكد أن اسم الفرع الرئيسي `main`.
   - ارفع الملفات إلى المستودع الخاص بك، لأن المشروع يحتوي على نظام دخول وبيانات تطبيق.
4. افتح تبويب **Actions** في المستودع.
5. اختر **Build Android APK** ثم اضغط **Run workflow**، أو انتظر تشغيله بعد رفع الملفات إلى فرع `main`.
6. إذا اكتملت العملية بنجاح، افتح تشغيل workflow الناجح، ثم نزّل artifact باسم `makhzan-owlad-shalba-debug-apk`.
7. فك ضغط artifact؛ ستجد داخله `app-debug.apk`، وانقله إلى هاتفك لتثبيته.

## ملاحظات مهمة

- هذا مشروع مُعدّ للبناء السحابي، وليس APK مبنيًا بالفعل. نجاح البناء يعتمد على بيئة GitHub Actions والتبعيات.
- قد تتغير واجهة GitHub أو سياسات الاستخدام. يتطلب البناء اتصال إنترنت وحساب GitHub.
- اختبر التطبيق قبل استخدامه لبيانات حقيقية. بياناته حاليًا تحفظ في `localStorage` على الجهاز؛ حذف بيانات التطبيق أو إعادة تثبيته قد يؤدي إلى فقدانها إذا لم تتوفر نسخة احتياطية.
- بيانات الدخول الافتراضية في HTML المرسل: `admin` / `123456789`. غيّرها بعد أول دخول، ولا تنشر المستودع علنًا.
- تكامل النسخ الاحتياطي في HTML الأصلي يستخدم واجهة Filesystem قديمة؛ يجب اختباره وتحديثه عند الحاجة قبل الاعتماد عليه.
